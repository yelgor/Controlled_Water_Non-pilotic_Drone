# imu_test — тести IMU і GPS

Перевіряли, наскільки точно IMU і GPS тримають курс і положення, щоб вибрати датчики
і підхід для навігації катера.

## Що всередині

| Шлях | Що це |
|---|---|
| `src/main.cpp` | прошивка ESP32-S3: IMU ~200–240 Гц, фільтр Madgwick, GPS NEO-6M, усе в CSV у Serial (921600) |
| `platformio.ini` | налаштування PlatformIO |
| `tools/imu_logger.py` | запис потоку з плати у файл `data/imu_<дата>_<тег>.csv` |
| `tools/analyze_imu.py` | шум, зміщення, дрейф, варіація Аллана, кут повороту |
| `tools/calib_accel6.py` | калібрування акселерометра за 6 положеннями |
| `tools/calib_mag.py` | калібрування магнітометра (hard iron + soft iron) |
| `tools/kalman_compare.py` | простий фільтр Калмана для крену й нахилу і порівняння з Madgwick |
| `tools/walk_trajectory.py` | траєкторія ходьби з IMU (крокомір) |
| `tools/gps_imu_walk.py` | EKF гіро + кроки + GPS для прогулянки |
| `tools/gps_imu_drive.py` | EKF гіро + GPS для поїздки (машинка/катер) |
| `data/` | графіки (`*.png`) і текстові звіти (`*.txt`) |

Сирі CSV у гіт не додані: вони великі й містять GPS-координати.

## Як запустити

```bash
pio run -t upload                                  # прошити плату
python3 tools/imu_logger.py --tag static -d 600    # записати 10 хв нерухомо
python3 tools/analyze_imu.py data/imu_..._static.csv
python3 tools/gps_imu_drive.py data/imu_..._drive.csv --dropout 60,20
```

Команди в моніторі порту: `c` — перекалібрувати гіро, `m` — 6DOF/9DOF, `r` — скинути орієнтацію, `h` — заголовок CSV.

## Головні результати

1. **Гіро NXP FXAS21002**: дрейф курсу ~0,3 °/хв. **LSM9DS1** — ~2,5 °/хв, у 8 разів гірше. Для курсу краще NXP.
2. **Калібрування гіро на старті**: 5 с нерухомо, інакше зміщення псується.
3. **Акселерометр NXP** у спокої показує 1,044 g — потрібне 6-гранне калібрування.
4. **Магнітометр** поруч із залізом показує ~0,97 Гс замість ~0,5 — калібрувати треба на зібраному катері.
5. **GPS NEO-6M**: при 7 супутниках трек зсувається на 25–35 м, при 9–12 супутниках збіг 2–5 м.
   Стартувати після ≥ 9–10 супутників.
6. **EKF гіро + GPS**: 30 с без GPS — відхилення 8–11 м; з GPS — 3–6 м.
7. Подвійне інтегрування акселерометра для положення не працює (15–33 м за хвилину).

## Увага: піни GPS

Тут GPS підключений як `PIN_GPS_RX = 15`, `PIN_GPS_TX = 16`. В основній прошивці
(`feature/pid-control`, `firmware/include/config.h`) навпаки: RX 16, TX 15 — так зібраний катер.
