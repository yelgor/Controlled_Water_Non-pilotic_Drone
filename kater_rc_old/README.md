# kater_rc_old — стара версія ручного керування катером

> **Застаріло.** Це проміжна прошивка, без GPS та IMU.
> Актуальний код катера — у гілці `feature/pid-control` (папка `firmware/`).

ESP32-S3 + приймач ELRS (CRSF) + серво керма + мотор (ESC). Керування тільки з пульта.

Що вміє:
- кермо (CH1) і газ (CH3) з пульта;
- обмеження ходу керма від газу (більше газу → менший поворот);
- обмеження газу від керма (сильніше кермо → менше газу), плавне, щоб катер не перекинувся;
- ручний режим налаштування серво з монітора порту (115200).

Підключення:

| Що | GPIO |
|---|---|
| Серво (сигнал) | 4 |
| ESC мотора | 5 |
| TX приймача → ESP | 17 |
| RX приймача ← ESP | 18 |

GND серво, ESC, приймача і ESP32 спільний.
