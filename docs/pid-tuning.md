# Налаштування PID на воді

Інструкція для аероглісера з цього репозиторію. Порядок важливий: **компас → курс (P → D → I) → швидкість**.

## 0. Що таке P, I, D простими словами

- **P (пропорційна)** — «чим більше збився з курсу, тим сильніше повертай кермо».
  Мало — човен лінивий, багато — виляє «змійкою».
- **D (похідна)** — «гальмо»: якщо човен уже швидко повертає до цілі, кермо заздалегідь
  відпускається. Прибирає перелітання і виляння.
- **I (інтегральна)** — «терпіння»: якщо човен довго тримається трохи збоку (вітер, кривий трим),
  кермо поступово додається. Забагато — повільні великі хвилі.

## 1. Перед першим виходом на воду (на березі, по USB)

1. Підключи плату в USB-порт, через який прошиваєш (вбудований USB чипа, `/dev/cu.usbmodem…`). `pio device monitor`.
2. `status` — мають бути `компас: OK`, `пульт: OK`. GPS може бути `НЕМА` (під дахом це нормально).
3. **Пропелер ЗНЯТО.** Перевір:
   - тумблер ARM вгору при газі не на нулі → **не** армиться;
   - газ на нулі, ARM вгору → `MANUAL`, мотор слухається газу, але не більше 30%;
   - вимкни пульт → за пів секунди `FAILSAFE`, мотор стоп; після ввімкнення — треба перещелкнути ARM.
4. Кермо: стік вправо → кермо повертає ніс вправо. Якщо навпаки: `set rud.rev 1`, `save`.

### Компас

1. Зібраний човен (мотор, батарея, дроти — на своїх місцях), подалі від заліза й машин.
2. `cal start` → повільно покрути човен 2–3 повних кола і понахиляй в усі боки (20–30 с) → `cal stop` → `save`.
3. Перевір напрямки (`status`, поле «курс»):
   - ніс на північ (компас у телефоні) → ≈ 0°;
   - повертаєш ніс **праворуч** (за годинниковою) → курс **росте** (0 → 90 на схід).
   - Якщо росте не туди або «схід» показує 270° — осі сенсора не збігаються з човном:
     поміняй знаки в `firmware/include/config.h` → `kMagMap` (спершу Y). Це один раз.
4. Нахили човен на 20° — курс не повинен стрибати більше ніж на кілька градусів.
5. `set mag.decl 8` — магнітне схилення для України (~+7…+9°). Для утримання курсу не обов'язково.

## 2. Безпека на перших заїздах

- `thr.max` = **0.30** (30% газу). Не підвищуй, поки курс не тримається стабільно.
- Тихе місце, без людей і човнів, слабкий вітер.
- Палець завжди на тумблері HOLD: вимкнув — керуєш сам. Вимкнув ARM — мотор стоп.
- Перший HOLD — на прямій, коли човен уже йде рівно.

## 3. Курс: P → D → I

Режим: `spd.en 0` (газ — твоїм стіком). Тримай постійний газ ~20–25%.

Кожна спроба: розженись → увімкни HOLD → **стіком керма коротко збий човен** на 20–30° (або
`hdg <новий курс>` по USB на стенді) → дивись, як повертається → вимкни HOLD.
Після заїзду: `log list`, `python3 tools/get_log.py <порт> <n>`, `python3 tools/plot_log.py logNNN.csv`.

### 3.1 P

| `hdg.kp` | Що бачиш | Що робити |
|---|---|---|
| 0.01 (старт) | повертається повільно, без перельоту | ×1.5 |
| … | повертається швидко, 1 невеликий переліт | **це воно**, далі D |
| … | виляє «змійкою», не заспокоюється | ÷2 |

На графіку: «помилка курсу» плавно йде до 0; `rudder` не впирається в ±1 надовго.

### 3.2 D

Почни з `hdg.kd` ≈ `hdg.kp` × 0.3 (наприклад, kp 0.03 → kd 0.01).

- Переліт зменшився → добре, можна трохи підняти Kp.
- Кермо «тремтить» дрібно (видно на графіку `hdg_d` і `rudder` — пилка) → менший kd або більший `hdg.dtau` (0.2–0.3).

### 3.3 I

Тільки якщо човен стабільно тримається на 3–10° збоку (вітер, трим).

- `hdg.ki` = `hdg.kp` × 0.05 … 0.1. Повільно збільшуй.
- Повільні великі хвилі (період 10+ с) → I забагато.
- На графіку `hdg_i` має повільно вийти на постійне значення, а не рости без кінця.
- Інтеграл автоматично заморожується, коли газ < `hdg.minthr` (кермо без потоку не діє).

## 4. Швидкість

Коли курс тримається добре:

1. Подивись у лозі, яка швидкість GPS при, скажімо, 25% газу. `spd.ff` ≈ газ / швидкість
   (25% і 2 м/с → `spd.ff 0.12`).
2. `set spd.sp <швидкість>`, `set spd.en 1`. Тепер у HOLD газ іде від регулятора, стік газу ігнорується
   (поки є GPS; без GPS — знову стік).
3. `spd.kp` від 0.1: швидкість ловиться повільно → більше; газ «гуляє» туди-сюди → менше.
4. `spd.ki` 0.02–0.05 прибирає залишкову різницю.
5. GPS оновлюється 5 разів/с і шумить на малій швидкості (< 1 м/с) — не женися за ідеалом там.

## 5. Що дивитись у телеметрії

| Колонка | Нормально | Проблема |
|---|---|---|
| помилка курсу | швидко до 0, ≤ 1 переліт | «змійка» → менше P / більше D |
| `rudder` | рідко торкається ±1 | весь час ±1 → забагато P, або кермо слабке (мало газу) |
| `hdg_d` | плавна | пилка → більше `hdg.dtau` або менше kd |
| `hdg_i` | виходить на полицю | росте без кінця → кермо не може компенсувати (трим!) |
| `throttle` | ≤ `thr.max` | — |
| `gps_ok`, `imu_ok`, `rc_ok` | 1 | 0 → див. підключення/антену |
